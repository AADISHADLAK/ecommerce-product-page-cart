# ecommerce-product-page-cart
# E-Commerce Product Page with Shopping Cart

A responsive e-commerce product page built using HTML, CSS, and JavaScript. This project demonstrates product browsing, search and category filtering, and interactive shopping cart management.

## Features

- Responsive product grid for desktop and mobile screens
- Product search functionality
- Category-based product filtering
- Add products to the shopping cart
- Increase or decrease item quantities
- Remove items from the cart
- Automatic cart total and item-count updates
- Product images and prices displayed in product cards
- Demo checkout functionality

## Technologies Used

- **HTML5** — Page structure and content
- **CSS3** — Styling, responsive layouts, and user interface
- **JavaScript (ES6+)** — Search, filtering, cart state, and price calculations

## Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension, or open the file directly in your browser.
